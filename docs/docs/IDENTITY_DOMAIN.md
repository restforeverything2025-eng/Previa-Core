# Identity Domain

## Identity Provider

Confirms identity.

---

## Identity

Represents a verified identity from a provider.

Identity does not own business data.

---

## Customer Session

Represents the current authenticated Customer.

Applications use the session.

Core defines it.

---

## Current Customer

The current Customer available to the application.

Business logic works with Current Customer.

---

## Architecture Rule

Identity is temporary.

Customer is permanent.
