# Customer

## Purpose

Customer represents a person interacting with PREVIA.

Customer is independent of authentication providers.

Telegram, Email or any future provider only confirms identity.

---

## Minimum Customer

Every Customer has:

- Customer ID
- Display Name
- Identity Provider
- Identity ID

---

## First Features

- Favorites
- Customer Session

---

## Future Features

- Personal Search Requests
- Purchase History
- Reserved Items
- Loyalty Program

---

## Architecture Rule

Customer belongs to PREVIA Core.

Authentication belongs to applications.
