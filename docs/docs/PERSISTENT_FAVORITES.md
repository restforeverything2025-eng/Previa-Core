# PREVIA Persistent Favorites

## Purpose

Persistent Favorites allow Customers to keep their favorite products across all devices.

Favorites belong to the Customer rather than to a browser.

Authentication is required only when a Customer wants to save favorites permanently.

---

---

# Rules

A visitor may use favorites without authentication.

Authentication is optional.

Authentication becomes necessary only for synchronization.

Favorites always belong to a Customer.

Favorites are synchronized across all authorized devices.

---

# Synchronization

If a Customer signs in for the first time:

Local Favorites

↓

Merge

↓

Customer Favorites

If the Customer already has favorites:

Merge without duplicates.

---

# User Experience

Visitors never lose local favorites during authentication.

Synchronization happens automatically.

No manual import is required.
