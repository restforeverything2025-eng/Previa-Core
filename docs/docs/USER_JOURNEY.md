# PREVIA User Journey

## First Visit

Visitor opens PREVIA.

No account is required.

Visitor can browse the catalog freely.

---

## Discover

Visitor explores products.

Visitor can open product pages.

Visitor can add products to local favorites.

---

## Favorite

When the first favorite is added:

Favorites are stored locally.

No authentication is required.

---

## Synchronization

When the Customer wants to keep favorites across devices:

PREVIA offers Telegram Sign In.

Authentication is optional.

---

## Identity

Telegram verifies identity.

PREVIA finds or creates a Customer.

---

## Customer

Customer receives:

- synchronized favorites;
- future notifications;
- order history;
- saved searches.

---

## Future

The same Customer journey should remain valid regardless of the authentication provider.
